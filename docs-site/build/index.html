What you get

Local Speech-to-Text

Vosk-powered STT runs on your machine. 20+ language models. No cloud APIs needed.

Template System

Create, manage, and share prompt templates with YAML frontmatter. Sync community templates from GitHub.

Multi-Provider LLM

OpenRouter, OpenAI, Ollama, LM Studio, or any OpenAI-compatible endpoint.

Single Docker Container

One container, one command. Data persisted to ~/getthatquick via bind mount.

Chat Interface

Streaming responses, markdown rendering, code highlighting, thinking tokens, plan mode.

Self-Hosted

No accounts, no telemetry, no cloud dependency. Everything stays on your machine.
